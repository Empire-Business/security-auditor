# Contrato compartilhado

Versão do protocolo: 2.0. O catálogo é mantido no security-auditor; OMNX recebe cópia gerada em
control-index.json. Request/response são compartilhados byte a byte e têm origem no especialista.
Schemas de projeto/Tasks/migração e runtime comum são mantidos com OMNX.

Não editar cópia derivada isoladamente. Após mudanças coordenadas, sincronizar pacotes, executar suites,
atualizar versão/compatibilidade conscientemente e regenerar integrity.json/ZIP. Hash identifica bytes,
não torna a política externa confiável nem certifica independência do revisor.
